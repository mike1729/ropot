# Paired precision protocol

This procedure is frozen before the first cohort model request. One campaign
retains every request, failed attempt, budget charge and native proof.
The canonical 72 tasks are development 8 plus the first 32 in each construction
phase. The fixed primary 50 are development 8 plus the first 21 per phase.
The primary estimand is task-level pure 8-bit versus pure 16-bit joint verified
actor AND synthetic success, separately for reply 0 and the final three-reply policy.
Primary completion requires all 200 assigned source cells on those 50 terminal.
Ten primary tasks belong to fresh confirmation; running them is fresh exposure.
Primary results are exploratory because 40 tasks were available for tuning.
Tuning uses development 8 plus the first 16 per phase. Fresh 32 are positions
17–32 per phase; extra 22 lie outside the primary panel. No task is replaced.
Tuning precedes fresh work. Even zero-based original 72 ordinal runs 8-bit first;
odd runs 16-bit first. Both sources and precision arms have independent histories.
Initial whole requests match across precision except model path/profile; ready
prompt text, IDs and EOS must agree when available. Repairs may differ.
The common recipe allows three total replies, 2,048 tokens each, 240 seconds,
temperature 0.2, top-p 0.95 and seeds 20261024, 20261025, 20261026.
Only existing bounded public feedback informs repair; no hidden/cross-arm hints.
Before fresh work all 160 tuning source cells must be usable terminal, with no
invalid controls or procedures. Recipe choice uses symmetric pooled summaries,
never the direction or magnitude of the 8-versus-16 contrast. Keep unchanged if
the summed pure-arm joint count is at least 24/80 and no actionable common failure
mode exists. Otherwise inspect pooled format, truncation, public feedback and
resource failures for a justified COMMON revision, review/freeze a new plan and
rerun both arms' 40 tuning tasks. If none is justified, record unchanged with a
below-target limitation. All fresh tasks wait for the latest fixed recipe/decision.
Prior exposure before the decision defeats freshness within this campaign;
cohort restrictions protect cross-campaign use. A new plan supersedes older plans.
Each trial uses only its own members; superseded results and costs stay separate.
The cumulative acquisition union remains separate from paired analyses.
Reference gating and candidate verification use the pinned native contract.
Guarded execution/resource failures are distinct from unproven/failed controls.
Well-formed premature/duplicate decisions or fresh-before-decision remain invalid
but publishable; malformed schema/hash/request bindings reject. A decision needs
generation completion, native verdict and closure evidence at its own prefix.
Reserved limits and all observed costs remain charged; missing measurements are
unknown, never zero. Historical mechanics counts are transcribed from the pinned audit.
Matched initial and independently repaired policy costs use parent cold wall,
including setup/hash/load/generation/cleanup, known sums and unknown coverage.
Report median 16/8 wall ratios only with positive denominators. Native generation
rates use complete validated terminal evidence independently of program success;
the timer starts after the first token while its n+1/EOS convention counts it.
Neither measure establishes GPU-only time or time to first token.
